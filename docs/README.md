# Evermore Design Documentation

> Game Design Bible
> World: Arkadion
> Status: Foundational Design

This directory holds the design documentation for **Evermore**, split from the
original single `GAME_DESIGN.md` into focused documents. The original file
defined the "why" of Evermore; these documents preserve that philosophy and add
the systems detail that expands from it.

## How these documents relate

The philosophy layer is authoritative. Systems documents must support the
principles in `philosophy/`, never contradict them. Where a system makes a
concrete design choice, it should trace back to a principle here.

```
philosophy/   The "why" — vision, discovery principles, design rules
world/        Arkadion itself — the world, exploration, cartography
systems/      The "how" — identity, disciplines, arts, skills, unlocks, professions
social/       Reputation, the knowledge economy, first-discovery recognition
world-events.md   Changes to the world over time
```

## Reading order

1. `philosophy/vision.md` — start here; the core identity of Evermore
2. `philosophy/discovery-principles.md` — discovery as the central pillar
3. `systems/identity-overview.md` — the four systems that make a character
4. Everything else as needed

## Core principle

Evermore is a world where knowledge spreads, discoveries become history, and
players are remembered for how they changed their understanding of Arkadion.

The game can be documented. The world cannot be exhausted.
