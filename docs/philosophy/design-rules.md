# Design Rules

Future systems should support the identity of Evermore. When a design choice is
in question, it should be resolved in favor of these rules.

## Evermore Should Encourage

- curiosity
- experimentation
- exploration
- mastery
- specialization
- cooperation
- personal expression
- meaningful contribution

## Evermore Should Avoid

**A single optimal path.** There should not be one correct way to play.

**Progression based only on numbers.** Power alone should not define success.

**Disposable content.** Discoveries and accomplishments should feel meaningful.

**Artificial secrecy.** The game should not rely on hiding information forever.
(See `discovery-principles.md` — Evermore protects the pace and
integrity of discovery, not its permanence.)

**Forced identity.** Players should have room to develop unique characters.

**Knowledge becoming obsolete.** Discoveries should continue having value after
they become common knowledge.

**A world that exists only for players.** Arkadion should feel ancient, alive,
and independent.
