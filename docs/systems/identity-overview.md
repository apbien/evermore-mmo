# Character Identity Overview

Evermore does not use traditional permanent classes. Character identity is
created through four interconnected systems.

| System     | Question                             |
| ---------- | ------------------------------------ |
| Discipline | What kind of adventurer am I? Which Arts may I pursue? |
| Art        | How do I express my specialization?  |
| Skill      | What capabilities have I learned?    |
| Profession | How do I contribute to civilization? |

> **Note:** Discipline does double duty. It defines combat identity *and* acts as
> the access key that determines which Arts a player may unlock and equip. See
> `disciplines.md` and `arts.md`.

Together these systems create personal identity. A player's combat identity and
production identity do not need to match — a Vanguard can be a master smith.

## How the systems interlock

- A **Discipline** sets your role and grants access to a list of **Arts**.
- **Skills** are learned capabilities, ownable independently of Discipline.
- An **Art** is a lens that recolors a Skill's expression. Which Arts you may
  unlock/equip is gated by your active Discipline.
- **Professions** run parallel to all of this, answering "what do I create?"

Detailed rules for each live in their own documents. The critical cross-cutting
system — how Arts and Skills unlock — is defined in
`unlocks-and-discovery.md`.
